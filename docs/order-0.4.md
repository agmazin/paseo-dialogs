# Порядок групп - 0.4.0, AGM-30

20.10.2026. Готово к приёмке на отдельном демоне Paseo 0.12.0,
127.0.0.1:6782, home в Library/Developer/paseo-dialogs/test-home.
Основной демон, его плагин, окна Paseo и личный Chrome не изменялись.

## Поведение

Группа переносится за строку названия вместе с агентами, терминалами и архивом.
Обычный клик сворачивает и разворачивает. Счётчик и "+" не начинают перенос.
Escape, потеря фокуса окна, pointercancel и размонтирование отменяют перенос.
Сохранение происходит только после отпускания мыши. Родной порядок Paseo не меняется.

`groupOrder` хранится атомарно в state.json рядом с прежними настройками.
Старое состояние 0.3.0 читается с пустым порядком, затем дополняется видимыми ID.
Новые ID добавляются в конец, архивные и удалённые исключаются, вернувшиеся
добавляются в конец. Полный список читается с пагинацией; события архивации
обрабатываются сервером без открытого интерфейса. Операции порядка сериализованы.
RPC передаёт одну перемещаемую группу и следующую за ней, сохраняя чужие добавления.
Второй клиент получает изменения при обновлении данных, обычно до 4 секунд.
При ошибке записи порядок откатывается и интерфейс показывает сообщение.

## Сравнение с Paseo

На тестовом демоне через настройки включена галка "Показывать родной список Workspaces".
Родной проект перетащен мышью в отдельном headless Chrome. Сверены его DOM-стили
и код установленного web-бандла index-3d91adc9929fc38d33c6f16e7811ed52.js,
модули 4536 и 4543. Повторены:

- порог мыши строго больше 6 px;
- вертикальный перенос, выбор ближайшего центра группы;
- движение всего содержимого, увеличение 1.02, прозрачность 0.9, z-index 1000;
- сдвиг соседей с transform 200ms ease;
- обычный курсор pointer на строке, без придуманного grab;
- отмена Escape и отсутствие сворачивания после переноса.

Это адаптер в client/web.ts, а не импорт родного DraggableList.
[Публичный список runtime-модулей](https://paseo.sh/docs/plugins/reference#runtime-modules)
не содержит DraggableList, dnd-kit, Reanimated и gesture-handler. Приватный runtime
Paseo не вскрывается. Полное совпадение движка, включая его keyboard sensor и
автопрокрутку dnd-kit, не реализовано. Снимки подтверждают проверенное поведение
мышью на трёх группах, но не означают полную идентичность двух библиотек.

На телефонах, native-клиентах и компактной раскладке порядок только отображается.
Долгое нажатие не перехватывается. Родной mobile drag использует недоступный
плагину gesture runtime; применён прямо разрешённый карточкой вариант просмотра.
Нативное приложение телефона в этом прогоне не запускалось; компактный web-клиент
390x844 проверен отдельно, включая получение порядка со второго desktop-клиента.

## Проверки

- `npm run typecheck`, `npm test`: 6 тестов. Новый тест реальных серверных обработчиков
  проверяет миграцию старого состояния, сохранение и повторное чтение, добавление,
  архивирование, возвращение, сохранность свёрнутости, отказ записи и повторную попытку.
- `node tests/browser/group-order-live.mjs`: перенос, порог, Escape, простой клик,
  исключение счётчика и "+", меню, отдельный второй клиент, page reload и plugin reload,
  сохранение на диске, неизменность родного порядка, компактный вид. pageerror отсутствуют.
- `node tests/browser/group-order-extra.mjs`: сравнение в тёмной теме, родная настройка
  видимости и сохранность подвала, добавление новой группы в конец и удаление при архивировании.
- `node tests/browser/native-workspaces.mjs`: прежние проверки DOM-адаптера 0.3.0 проходят.
- Два клика "Агент" создали два пустых тестовых диалога. После их архивирования
  строка "Архив 2" раскрывается и показывает обе записи. Ходы агентов не запускались.
- Значки статусов и защита ручного имени проверены прежними unit-тестами; платный
  вызов ai-fast заново не выполнялся. Живой результат автоназвания версии 0.2.0
  задокументирован в verification.md, этот код не менялся.

Живые браузерные скрипты требуют работающий тестовый демон и подготовленные
три пространства agmazin, ЭкоЭксперт, CTG в drag-fixtures вне Яндекс.Диска.
Скрипт live также использует тестовый терминал в группе agmazin. Они не запускаются
из npm test и явно закреплены за тестовым портом. Создание и архивирование фикстур
выполнялось CLI с явным --host. node_modules остаётся симлинком вне синхронизации.
