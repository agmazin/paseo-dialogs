## Поведение

- Чат верхнего уровня в статусе "Готово" или "На проверку", у которого есть подагент
  со `status=running`: в правом нижнем углу иконки два кружка `SubagentBadge pair`,
  слева шеврон, подсказка строки "Работают подагенты: N".
- Шеврон или клик по паре раскрывает ветку под чатом. В ветке только работающие
  неархивные подагенты: строка 28px, отступ 44, иконка провайдера, название, время
  последней активности, один кружок `SubagentBadge` с центром 14.5/14.5 (там же, где Badge).
  Клик открывает подагента, как обычный диалог. Ветка свёрнута по умолчанию, состояние
  не сохраняется между запусками.
- Чат в работе - обычная крутилка Badge, пары нет. Ожидание разрешения и ошибка
  сохраняют свои значки: они важнее работающих подагентов. Нет работающих подагентов -
  нет ни пары, ни шеврона.
- Свёрнутая папка считает такой чат в "В работе". В макете был отдельный счётчик пары;
  по постановке задачи выбран общий счётчик "В работе".

Кружок один на все места: точка 5x5, вырез 10x10 цветом фона строки, крутилка 10px
с рамкой 1.2. Пара делит одно значение анимации, поэтому кружки крутятся в одной фазе.

## Данные

Демон 0.12.0 отдаёт у подагента, созданного `paseo run` из сессии агента,
`parentAgentId` (проверено `paseo agent inspect`: `ParentAgentId` родителя). Метка
`paseo.parent-agent-id` тоже учитывается. RPC `dialogs.agents` добавляет к диалогам
верхнего уровня работающих неархивных подагентов; подписка клиента держит их в кэше,
пока они работают. Новый диалог из меню "+" берёт настройки только у диалогов верхнего уровня.
