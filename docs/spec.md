## Зачем

В Paseo у Александра проект AI OS с двумя рабочими пространствами, agmazin и ЭкоЭксперт, в каждом много вкладок-агентов.
Слева он видит только названия пространств, справа - вкладки одного из них. Нужно в левой панели видеть под каждым
пространством его диалоги со статусами, архив, создавать новые вкладки и быстро находить диалоги по коротким названиям.

## Решения Александра (не пересматривать)

1. Блок "Диалоги" стоит в шапке боковой панели над родным списком Workspaces (пункт `addSidebarHeaderItem`).
   Встроить строки внутрь родного дерева API плагинов 0.12 не даёт; патчить сам Paseo не будем.
2. Значки статусов - как на вкладках Paseo: голубая точка с крутящимся кольцом - "В работе", оранжевый круг с "!" -
   "Ожидает ввода", зелёная точка - "На проверку", красная - "Ошибка", без значка - "Готово".

6. Автоназвание в 1-2 слова - только новым агентам. Существующих и архив не переименовывать.

## Что видно и как ведёт себя

Блок "Диалоги":
- Заголовок "Диалоги" (цвет `foregroundMuted`), справа "+" - новое рабочее пространство.
- По группе на каждое активное рабочее пространство (не архивное, не background). Порядок - как в родном списке
  Workspaces, если SDK его отдаёт, иначе по дате создания.
- Строка группы: шеврон, имя пространства, справа число активных строк. У свёрнутой группы перед числом - чипы со
  значками и количеством: сколько ждут ввода, работают, на проверке, с ошибкой (только ненулевые). "+" появляется при
  наведении (на компактной раскладке виден всегда).
- Свёрнутость групп и архивов запоминается между перезапусками приложения.

Строки внутри группы (активные):
- Агенты пространства без архива и без сабагентов (`parentAgentId` или метка `paseo.parent-agent-id`), плюс терминалы

  "сейчас" (меньше 2 минут), ЧЧ:ММ сегодня, "вчера", дальше "28 сен".

- Клик открывает эту вкладку справа (агента или терминал) в его пространстве. Выбранная строка подсвечена.

Архив:

## Статусы: логика

Логика Paseo 0.12 (`deriveAgentStateBucket` из бандла приложения), её и повторяем:

```js
if ((agent.pendingPermissionCount ?? 0) > 0 || agent.attentionReason === "permission") return "needs_input"; // Ожидает ввода
if (agent.status === "error" || agent.attentionReason === "error") return "failed";                       // Ошибка
if (agent.status === "running") return "running";                                                          // В работе
if (agent.requiresAttention) return "attention";                                                           // На проверку
return "done";                                                                                             // Готово
// агрегат группы: needs_input > failed > running > attention > done
```

Отличие от Paseo только в "На проверку": вместо `requiresAttention` (Paseo снимает его при фокусе вкладки) плагин держит
свою отметку "не просмотрено". Ставится, когда ход агента завершился (`server.on("agent.turn_ended")`, outcome completed).
Снимается, когда в чате этого агента виден конец последнего ответа. Предлагаемый путь: на конец хода дописать в таймлайн
агента невидимую строку-маркер (`paseo.agents.ref(id).timeline.append`, свой renderer нулевой высоты); маркер в Electron/web
ловит видимость через IntersectionObserver (только в `client/web.ts`, с проверкой `Platform.OS === "web"`) при видимом окне,
в нативных клиентах - по монтированию. Отметки хранить на стороне демона, чтобы все клиенты видели одно и то же.
Если путь не работает - доложить в карточке и временно взять родной `requiresAttention`, не выдумывать эвристик.

Цвета значков Paseo (тёмная / светлая тема): running `#5caaf6` / `#268ae0`, success `#35c264` / `#299f51`,
warning `#db932e` / `#b37824`, danger `#f7796d` / `#f12e2f`. Если в `theme.colors` плагина есть статусные цвета -
брать их. Размеры: точка 7-8 px с вырезом цвета фона строки, круг "!" 12 px.

## Автоназвания новых агентов

- Кандидаты: агенты, созданные после установки плагина (`agent.created`), верхнего уровня (не сабагенты), в
  не-background пространствах.
- Когда: после первого хода с outcome completed (`agent.turn_ended`), один раз на агента.
- Условие: название всё ещё авто - пустое или совпадает с началом первого сообщения пользователя (Paseo ставит вкладке
  первые 60 символов первого сообщения). Название, заданное руками или при создании, не трогать никогда.
- Название: 1-2 слова по-русски, тема диалога, без кавычек и точки, с заглавной буквы, не длиннее 24 символов.
  Пример: "Посмотри, почему с сайта экоизыскания перестали приходить заявки..." -> "Пропавшие заявки".
- Модель: профиль `ai-fast` через CLIProxy, OpenAI-совместимый `/v1/chat/completions`. Ключ и адрес - `CLIPROXY_KEY_MAC`
  и `CLIPROXY_URL_MAC` из `/Users/agmazin/Yandex.Disk.localized/public/projects/agmazin/.secrets/cliproxy.env` (тот же
  потребитель, что WhisperKey и Konspekt; читать файл на стороне демона при вызове). Ключ не логировать, не коммитить,
  не показывать в отчёте. В таблицу потребителей
  `/Users/agmazin/Yandex.Disk.localized/public/projects/agmazin/deploy/dokploy/cliproxy/README.md` дописать плагин в
  строку Мака.
- Переименование - тем же механизмом, что `paseo agent update <id> --name "..."` (метод SDK или CLI с демона).
- Ошибка модели или сети - оставить название как есть, строка в `paseo plugin logs`.

## Ограничения

- Не перезапускать демон Paseo (`paseo daemon restart` или `paseo restart`): это убьёт агентов, включая оркестратора.
  Только `paseo plugin install` / `paseo plugin reload`. Плагины уже включены (`pluginsEnabled: true`).
- Не трогать окно Paseo Александра: не активировать, не кликать, не двигать. Интерфейс проверять в отдельном клиенте:
  например, веб-интерфейс демона (`features.webUi.enabled`) в безголовом Chrome с отдельным профилем, если включается без
  перезапуска демона (`paseo reload`); иначе скриншоты окна в фоне (`screencapture -x -l <id>`) и проверку руками
  оставить оркестратору.
- В пространствах agmazin и ЭкоЭксперт ничего не создавать, не переименовывать и не архивировать. Для проверки создать
  отдельное пространство "Тест Диалоги" и тестовых агентов в нём, после проверки заархивировать.
- `node_modules` не класть в Яндекс.Диск: симлинк на каталог вне синка, например `~/Library/Developer/paseo-dialogs/`
  (так сделано с `.build` у WhisperKey). Сборочных артефактов в git нет.
- Тексты интерфейса на русском. Типографика везде, включая отчёт: только дефис "-", прямые кавычки, без длинных тире,
  ёлочек, тильды и знака рубля.
- Цвета текста только из `theme.colors`, светлая и тёмная тема, компактная раскладка (мобильный Paseo) не ломается.
- Только React Native примитивы в клиенте, DOM - только в `client/web.ts` (правила навыка
  `/Users/agmazin/.claude/skills/paseo-plugin/SKILL.md`).
