# Открытие диалогов 0.9.2

Стенд: оригинальный app-dist Paseo 0.13.0 из установленного приложения,
Electron 44.2.0, отдельный демон 0.12.0 на 127.0.0.1:6786.
Личное окно, агенты и вкладки Александра не использовались.

## Причины и воспроизведение

Обычные повторные открытия и reload 0.9.1 сами по себе проходили.
При контролируемой задержке history commit экрана navigate на 250 мс
0.9.1 оставался на экране плагина: единственная проверка адреса через 50 мс
пропускала переход. Это воспроизведение гонки, а не утверждение, что исходная
длительная сессия Александра была воспроизведена целиком.

Второй сценарий воспроизведён без задержки workspace intent:
архивный агент открывался первый раз, после закрытия повторный deferOpenTab
оставался неприменённым в уже сохранённом пространстве.

## Исправление

Каждый клик получает request id. Destination ждёт именно свой адрес до 5 секунд,
отменяет устаревшую попытку и показывает ошибку вместо молчаливого отказа.
На native остаётся штатная навигация. Активные агенты открываются публичным API.

Для архива web-адаптер находит модуль layout store по сигнатуре и проверяет методы.
Он снимает hideAgent и вызывает openTab с pin=true, затем открывает канонический
маршрут пространства. Поиск не хранит экземпляр плагинного клиента и не зависит
от singleton Вкладок. Перед изменением проверяется актуальность запроса.
При отсутствии контракта остаётся прежний workspace intent.

## Проверка

`npm run typecheck`, `npm test`.
`node tests/browser/desktop-reopen.mjs` - только отдельный демон 6786.
Тест использует скрытый Electron и отдельный профиль, не захватывает фокус.
Проверяются крестик, Cmd+W, обновление Диалогов без reload окна,
смена пространства, повторное открытие архива и полный экран архива.
Состояние агентов проверяется через CLI: активный остаётся активным,
архивный остаётся архивным. Ширины снимков: 1440, 800, 390.
Итог - desktop-reopen-0.9.2.json, снимки - shots/0.9.2/.

Три IPC-обработчика управления браузером на стенде возвращают null:
встроенный браузер не относится к проверке открытия агентов.
