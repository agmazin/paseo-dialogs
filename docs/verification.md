  "Зелёный чай" через ai-fast. Отдельный агент "Ручное имя" сохранил название

## Ограничения для приёмки

- Публичный openAgent не передаёт pin=true. У активных агентов переход проверен.
  У архивных без закреплённой вкладки Paseo может оставить прежний чат. Родная
  "История" передаёт pin=true и открывает тот же агент. Приватные хранилища Paseo
  не патчились; автоматического разархивирования нет. Этот пункт исходного
  "Готово, когда" не закрыт публичным API 0.12.0.
- Браузер регистрируется через navigation.openBrowser только в Electron.
  В изолированном web-клиенте его нет; живая проверка Electron оставлена приёмке.
  В визуальном сравнении показана полная версия меню с браузером.
- Родного черновика нет: агент создаётся SDK с моделью, thinking и режимом
  последнего агента пространства. "Изменить профили" скрыто.
- Терминал с закрытой native-вкладкой и клиенты без DOM открывают пространство.
- PNG-копии SVG для native и толщина Lucide описаны в visual-parity.md.
- Обе боевые группы не использовались для тестов по запрету карточки.
