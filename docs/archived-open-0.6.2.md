# 0.6.2 - архивный диалог открывается вкладкой (21.10.2026)

Жалоба Александра: клик по архивному диалогу ("Опция Пасео") что-то мигает, но вкладка не открывается;
нужно, чтобы диалог открывался активной вкладкой и было ясно, куда вводится текст.

Причина. Диалоги открывали агента через `navigation.openAgent({ agentId })`. Архивного агента нет в живом
списке хоста, Paseo 0.12 уходит на `/h/<srv>/agent/<id>`, оттуда в пространство без закрепления вкладки,
и активной остаётся чужая вкладка (на тесте - "Чёрный список"). Родная "История" открывает тот же диалог
правильно: `navigateToAgent({ workspaceId, pin: true })`, то есть маршрут `/h/<srv>/workspace/<ws>?open=agent:<id>`.

Решение. `openPinnedAgent` в `client/web.ts`: тот же маршрут через `history.pushState` + `popstate`
(роутер Paseo перечитывает адрес), только на вебе и при обычных id; иначе прежний `openAgent`.
Используется для строк архива в боковой панели и на экране "Весь архив".

Проверка на тестовом демоне 127.0.0.1:6793 (home `/Users/agmazin/Library/Developer/paseo-tabs/test-home`),
безголовый Chrome: архивные "Тесты хаба" и "Импорт номеров" открываются активной вкладкой с плашкой
"Этот агент находится в архиве / Разархивировать" (`docs/archived-open-0.6.2.png`), живой диалог открывается
как раньше, клик из экрана "История" тоже; ошибок в консоли нет; typecheck, 15 тестов.
