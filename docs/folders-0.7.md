# Диалоги 0.7.0 - 22.10.2026

Переименование перенесено вручную из worktree folders поверх main 0.6.4. Имя плагина,
заголовок виджета, экраны и префиксы логов "Диалоги" сохранены. Новые надписи:
"Новая папка", "Переименовать папку", "Выберите другую папку", "в исходной папке".
Подсказка пути в окне создания - "Каталог: AI OS (public)".
В client, server, shared и index.* больше нет вхождений корня старого термина.

Причина наезда - Block в client/ui.tsx: на компьютере children выводились без ScrollView
и ограничения высоты. У 24 тестовых папок блок занимал 854 пикселя и заканчивался на y=990
при окне 1440x900, шапка сайдбара имела высоту 1 031 пиксель. Канбан - обычная SidebarRow,
его код и версия не менялись.

Теперь ScrollView используется на всех платформах. DOM-адаптер в client/web.ts читает
высоту контейнера сайдбара, шапки, соседних пунктов и нижнего меню через ResizeObserver.
Высота самого блока вычитается из замера шапки, поэтому изменение лимита не создаёт цикл.
Скрытая родная секция не резервирует место; видимой оставлено место. При изменении окна,
пунктов и видимости списка высота пересчитывается. Адаптер не меняет DOM Paseo;
на нативном телефоне остаётся предел 55% экрана.
