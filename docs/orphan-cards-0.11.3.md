# Карточки без родительской метки

Версия 0.11.3. Вложенный номер kanban.key распознаётся как карточка даже без
parentAgentId и paseo.parent-agent-id. Если метки kanban.key нет, проверяется
префикс названия вида "AGM-12-4: ". Метка имеет приоритет над названием.
Обычные номера AGM-N и диалоги без номера остаются видимыми.

Общий topLevel используется сервером для dialogs.agents, archiveCounts,
dialogs.archive и защиты автоназвания. Клиент применяет его при загрузке
агентов, выборе шаблона нового диалога, отображении папок и всего архива.
Компактный RPC и обновления подписки сохраняют kanbanKey, поэтому карточка
без префикса в названии не становится диалогом после преобразования slim.
Активные подагенты остаются в техническом наборе RPC для существующих веток;
самостоятельными строками папок они не отображаются.

## Почему возможна потеря метки в одном пространстве

В установленном Paseo 0.14.0 функция shouldDetachFromArchivedParent возвращает
isCrossWorkspace || hasOpenAgentTab(child.labels). Поэтому при архивации родителя
карточка с открытой отдельной вкладкой отсоединяется даже в том же пространстве.
detachedAgentLabelPatch удаляет и метку родителя, и метки открытых вкладок;
по текущим меткам уже нельзя восстановить факт ранее открытой вкладки.
Это объясняет механизм для ECO-3-14, но не доказывает исторический факт её
открытия: текущая запись и журнал не содержат снимка меток до отсоединения.
