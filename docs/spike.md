# Спайк AGM-28 - исторический отчёт 20.10.2026

Обновление: блокер версии снят оркестратором. Реализация 0.2.0 проверяется на
отдельном демоне 0.12.0. Актуальный итог - `verification.md`, перенос вида -
`visual-parity.md`. Ниже сохранены результаты первоначального спайка.

Версия исходников: 0.0.0-spike.1. Это диагностический каркас, не готовый плагин.

- После отказа `paseo plugin ls --json` вернул `[]`.

Версия установленного CLI не является версией уже работающего демона.
Понижение `requirements.paseo` только ради прохождения проверки не сделано.
Демон, его конфиг и окно Paseo не изменялись. Рабочие пространства и агенты
не создавались и не изменялись. Тестовый мусор в Paseo отсутствует.

## Три риска

1. Свой контент в шапке: SDK 0.12.0 принимает произвольный React-компонент
   `PluginSidebarItemProps`. Каркас с View, Text и Pressable проходит typecheck.
   Рендер в живом приложении не проверен из-за отказа установки.
2. Открытие агента: в шапке нет navigation, у PluginScreenProps есть
   `navigation.openAgent`. Каркас использует экран-переход с useLayoutEffect.
   Открытие вкладки и отсутствие мелькания ещё не проверены.
3. Родной черновик агента: в публичном контракте PluginClientContext и navigation
   SDK 0.12.0 нет вызова создания родного черновика. Для основной реализации
   предусмотрен разрешённый спецификацией SDK-fallback с настройками последнего
   агента. Он пока не реализован. Кроме того, публичная navigation не содержит
   openTerminal; способ открытия терминала требует отдельного спайка.

Контракты проверены по установленным `.d.ts`, текущему
[справочнику плагинов](https://paseo.sh/docs/plugins/reference.md) и чтением
бандла установленного приложения без его изменения.

## Что требуется для продолжения

Согласовать окно обновления живого демона до версии не ниже 0.12.0 с остановкой
активных агентов силами Александра/оркестратора. Перезапуск явно запрещён текущей
карточкой, поэтому исполнитель его не выполнял.

После обновления повторить установку, завершить три спайка и проверить
openTerminal. Затем реализовать спецификацию и выполнить весь её список приёмки.
Скриншотов сценариев пока нет: плагин не установлен. Логи успешного запуска,
автоназвания, маркеры "На проверку" и полный список "+" пока не реализованы.
Маркер на ход или постоянный id ещё не выбран.

Поиск `paseo-dialogs|AGM-28|плагин.*диалоги` по markdown проекта agmazin и этого
репозитория нашёл утверждённую спецификацию, но не дополнительные открытые
пункты. Спецификация и решения Александра сохранены без изменения.
