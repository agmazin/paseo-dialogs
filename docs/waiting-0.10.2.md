# Ожидание Александра в Диалогах 0.10.2

Оранжевый "!" использует существующий Badge needs_input. Причины скопированы из
waitingOf/waitsForAnswer Канбана: pendingPermissions/attentionReason=permission,
kanban=ask, kanban=review. По прямому заданию ask/review здесь имеют приоритет над
running/initializing. В Канбане они проверяются после running; его код не изменён.

RPC передаёт waitReason и всех неархивных потомков, включая остановленных промежуточных
агентов. Клиент применяет то же преобразование slim к событиям подписки. Модель проходит
цепочку родителей с защитой от циклов, считает каждого ждущего потомка один раз и
показывает его в раскрытой ветке. Архивные ветки не дают ожидание головному чату.
