# Родной список Workspaces - 0.3.0

Реализованы штатные Settings > Plugins > paseo-dialogs > Диалоги и сохраняемая
галка "Показывать родной список Workspaces", по умолчанию false. Значения
хранит registerSettings Paseo, обновление распространяется через useSettings.
Пока настройки не загрузились или недоступны, список не скрывается.

DOM-адаптер только в client/web.ts, Platform.OS web и некомпактный layout.
По согласованию оркестратора используется фактическая пара
sidebar-project-workspace-list-scroll + sidebar-display-preferences-menu.
Проверяется общий ограниченный контейнер: если в нём есть dialogs-block,
другой плагин или sidebar-footer, ничего не скрывается.
Сохраняется исходный inline display. Он восстанавливается при включении галки,
потере любой метки, переходе в компактный вид и cleanup плагина.
MutationObserver обрабатывает замену узлов и перезапись стилей.
Узлы не удаляются, подвал не меняется. На native-платформах адаптер не работает.

## Проверено на отдельном демоне 20.10.2026

Paseo 0.12.0, порт 6782, home в Library/Developer/paseo-dialogs/test-home.
Typecheck, 4 теста логики и headless Chrome тест
`node tests/browser/native-workspaces.mjs` проходят.
Браузерный тест проверяет скрытие, сохранение подвала, перерисовку, удаление
меток, восстановление inline display и безопасный отказ при попадании блока
плагина или подвала в найденный контейнер.

Живой тест в отдельном Chrome:
- галка выключена по умолчанию;
- заголовок Workspaces с кнопкой и дерево скрываются;
- блок Диалоги и подвал остаются видимыми;
- галка возвращает список, повторное выключение снова скрывает его;
- скрытие сохраняется после plugin reload;
- с версии 0.5.2 при ширине 390 px родной список также скрыт с выключенной галкой; Диалоги открывают и создают агента и переключают группы;
- ошибок pageerror нет, тестовый плагин running.

К карточке приложены снимки 01-before, 02-hidden, 03-restored,
04-checkbox-on и 05-compact. Это живой тест, не DOM-фикстура.
Основной Paseo не менялся. Включение в основной среде выполняет оркестратор.

Прежний блокер снят: sidebar-project-list отсутствует в DOM web-клиента,
поэтому оркестратор разрешил фактическую пару меток. При её исчезновении после
обновления Paseo остаётся безопасный отказ: список видим.
