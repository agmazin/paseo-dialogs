## Причина и исправление

Модель возвращала "Фокус и вкладки", но validTitle отвергал три слова.
Теперь допускается одно из служебных слов "и", "или", "для", "по", "в", "на"
между двумя смысловыми словами. Русские буквы, заглавная первая буква и максимум
24 символа сохранены; "Три лишних слова" по-прежнему не проходит.

firstPrompt читает timeline назад: before без cursor возвращает хвост,
при hasOlder следующая страница запрашивается по startCursor. Берётся самое раннее
пользовательское сообщение, даже если на последней странице уже есть более позднее.
Отсутствующий и повторный cursor прерывают обход. Пустая история читается до трёх раз
с паузами 500 мс. До получения сообщения кандидат не расходуется; следующему ходу
доступна одна попытка генерации. Set naming исключает одновременные попытки.
Все ранние выходы автоназвания имеют причину и ID в логе; ошибка содержит этап.
Текст запроса, ответ модели и секреты в лог не попадают.
