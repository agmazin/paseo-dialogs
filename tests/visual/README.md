# Визуальный стенд

`gallery.tsx.txt` - исходник галереи, реально использованной для сравнений.
Расширение txt исключает тестовую тему и регистрацию из production typecheck.
Копировать его как client/gallery.tsx отдельного тестового плагина, рядом с копиями
client/ui.tsx, web.ts, icons.ts, provider-paths.ts. Зарегистрировать Gallery как
экран gallery и пункт боковой панели. Устанавливать только на тестовом демоне.

Для левой половины сравнений используется исходный CSS и функции groupHTML,
archHTML, groupMenuHTML, wsFormHTML из prototype/v2.html с теми же тестовыми
названиями. Обе половины снимаются headless Playwright Chrome в deviceScaleFactor 1,
тёмной теме. Пунктирную объясняющую рамку прототипа сделать прозрачной, сохранив
размер; строку "Изменить профили" удалить как недоступную в SDK.
Снимки прикладываются к AGM-28, в git растровые результаты не хранятся.
