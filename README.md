# Диалоги - плагин Paseo

Блок "Диалоги" в боковой панели Paseo: под каждым рабочим пространством его агенты и терминалы со статусами как на
вкладках, свёрнутый архив, меню "+" как у вкладок и короткие автоназвания новых агентов.

- Спецификация: `docs/spec.md`
- Прототип: `prototype/v2.html` (открыть в браузере)

Установка, обновление и откат появятся здесь вместе с первой версией.
