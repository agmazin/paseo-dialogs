# Диалоги - плагин Paseo

Блок "Диалоги" в боковой панели Paseo: под каждым рабочим пространством его агенты и терминалы со статусами как на
вкладках, свёрнутый архив, меню "+" как у вкладок и короткие автоназвания новых агентов.

- Спецификация: `docs/spec.md`
- Прототип: `prototype/v2.html` (открыть в браузере)

Статус AGM-28 на 20.10.2026: спайк, установка заблокирована версией демона.
CLI имеет версию 0.12.0, но живой демон сообщает 0.11.4 и отклоняет плагин
с требованием `>=0.12.0`. Полная реализация и проверка интерфейса ещё не выполнены.
Доказательства и решение, необходимое для продолжения: `docs/spike.md`.

## Локальная проверка

Зависимости находятся вне Яндекс.Диска:
`/Users/agmazin/Library/Developer/paseo-dialogs/node_modules`.
В репозитории `node_modules` является симлинком на этот каталог.

```sh
npm run typecheck
paseo plugin install /Users/agmazin/Yandex.Disk.localized/public/projects/local/paseo-dialogs
```

Команда установки пока завершается ошибкой совместимости. Не понижать требование
версии без проверки всех используемых API. Демон не перезапускать без разрешения
Александра. После согласованного обновления повторить установку и спайк.

Для обновления установленной версии:

```sh
npm run typecheck
paseo plugin reload paseo-dialogs
paseo plugin ls
paseo plugin logs paseo-dialogs
```

Отключение: `paseo plugin disable paseo-dialogs`. Для отката исходников использовать
отдельную копию проверенного коммита и установку из её локального пути.
Спайк не создаёт собственное хранилище данных и не читает ключ CLIProxy.
